Welcome to the WebGIS Portal

This website presents a geographical overview of Perumkadavila Panchayat in Kerala. Explore the spatial distribution of administrative boundaries, roads, drainage and other geographical resources.

The project demonstrates how Geographic Information Systems (GIS) and web mapping can support geographical understanding and local-level planning.

Explore the Map

About the Study Area

Perumkadavila Panchayat is located in Thiruvananthapuram district, Kerala. This project is designed to organise and visualise geographical information about the study area.

Objectives

  • Present the geographical features of the study area.
  • Visualise administrative boundaries and local resources.
  • Display road and drainage networks.
  • Demonstrate the application of GIS in local planning.

Project Scope

  • Digital map visualisation
  • Geographical data organisation
  • Web-based interactive mapping
  • Resource information presentation

Methodology

Data Preparation

  • Collect relevant spatial and attribute data.
  • Check the coordinate reference system.
  • Prepare and style layers using QGIS.
  • Verify data accuracy and completeness.

Web Mapping

  • Prepare suitable web mapping data.
  • Display layers using Leaflet.
  • Provide map navigation and layer controls.
  • Publish the website using GitHub Pages.
The actual GIS layers, study-area boundary and spatial analysis results should be added only after the data have been prepared and checked.
